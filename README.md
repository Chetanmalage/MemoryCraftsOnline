# 🛍️ MemoryCraftsOnline

**MemoryCraftsOnline** is a full-stack e-commerce web application for discovering and purchasing personalized gifts, handmade crafts, and products that preserve special memories.

> 🚧 **Project Status:** Under Development

## 🎯 Project Goal

The goal of this project is to build a complete, real-world e-commerce application while gaining practical experience in frontend development, backend development, databases, REST APIs, authentication, payments, and deployment.
